# Placas de aventura · Segunda colección

Dieciséis PNG transparentes para los niveles de decoración, colecciones, mascotas, intercambios, visitas, constancia, caminatas y gemas de CozyWalk. El manifiesto contiene los objetivos y hashes SHA-256.

Las imágenes se consumen mediante enlaces HTTPS fijados a un commit. No se sustituyen los archivos de la primera colección ni las releases del ejecutable.
