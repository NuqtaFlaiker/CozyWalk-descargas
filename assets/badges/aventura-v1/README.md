# Placas de aventura de CozyWalk

Recursos PNG transparentes de la primera colección de seis logros: mascota inicial, apariencia, gacha de mascotas, intercambio, colección de muebles y metas semanales.

El manifiesto identifica cada objetivo, archivo y SHA-256. El juego utiliza enlaces HTTPS a estos archivos fijados a un commit para conservar versiones estables. Publicar estas imágenes no cambia la versión del ejecutable ni sustituye las releases de Windows.
