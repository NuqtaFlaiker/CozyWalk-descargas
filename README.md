# CozyWalk — descargas

Este repositorio no tiene código: solo guarda las versiones del juego para Windows.

**Descargar el juego:** [última versión](https://github.com/NuqtaFlaiker/CozyWalk-descargas/releases/latest)
→ en *Assets*, `CozyWalk.exe`. Las anteriores están en [Releases](https://github.com/NuqtaFlaiker/CozyWalk-descargas/releases).

El exe se actualiza solo: al abrirse revisa la última release de aquí (`version.json`), descarga la nueva,
se reemplaza y vuelve a abrirse.

**Publicar una versión** (desde el repositorio del juego, en `main`): `node scripts/publicar-pc.mjs <versión>`.
Pasos completos en el README de CozyWalk, sección "Publicar una actualización".
